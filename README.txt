# Карточный Синтез

Карточная игра на Godot 4 с механикой слияния карт.

## Требования
- Godot Engine 4.7.2 (с поддержкой .NET/C#)
- Скачать: https://godotengine.org/download

## Как запустить
1. Установите Godot 4.7.2 с поддержкой .NET
2. Скачайте проект (Code → Download ZIP)
3. Откройте Godot → Import → выберите `project.godot`
4. Нажмите Play (F5)

## Управление
- Перетаскивайте карты из руки на поле (Drag & Drop)
- Одинаковые карты одного уровня сливаются при перетаскивании друг на друга
- Нажмите "Завершить ход" для применения эффектов

## Механика стихий
- 🔥 Огонь — наносит урон врагу
- 💧 Вода — лечит игрока
- 🛡️ Земля — даёт щит (поглощает урон)
